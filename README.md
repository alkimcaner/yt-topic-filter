# YT Topic Filter (Brave extension)

Hide/show YouTube video cards by topic. Classification runs against a local decision server at `http://localhost:9931/v1/systemone`.

## Install

1. Open `brave://extensions`, enable Developer mode.
2. Load unpacked → select this folder.
3. Run the decision server on `localhost:9931`.
4. Open YouTube and use the `Topic filter` top-bar button.
