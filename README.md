# YT Topic Filter — Local AI (Brave extension)

Categorize YouTube videos by topic with a **local multilingual zero-shot model** (`Horizon-Labs/multilingual-zeroshot-small`, q8, ~260 MB, runs on CPU/WASM) and **hide / show video cards per topic**. No server needed. Works on non-English titles too.

## How it works

1. Content script scans YouTube video cards (`ytd-rich-item-renderer`, `ytd-video-renderer`, `ytd-compact-video-renderer`, `ytd-grid-video-renderer`, Shorts, new `ytd-lockup-view-model`, …), extracting **title + channel + videoId**.
2. Offscreen document runs one batched NLI pass per video (all topic pairs in a single forward pass): premise is the video **title only** (channels were measured to mislead: +7pts without them), hypothesis `This video is about {topic name}.` Top entailment score wins.
3. A colored badge (`Topic · 87%`) is overlaid on the thumbnail; cards whose topic is unchecked are hidden.
4. Results are cached by `videoId` in `chrome.storage.local`. If the model isn't loaded, cards get no badge (nothing is cached; Load the model, then Rescan).

## Install in Brave

Prerequisite: [Bun](https://bun.sh) (only needed to rebuild the bundled worker after editing it).

1. `bun install && bun run setup && bun run build` (required: installs deps, fetches the vendored ORT runtime, generates the worker bundles).
2. Open `brave://extensions`, enable **Developer mode**.
3. **Load unpacked** → select this folder (the one containing `manifest.json`).
4. Open YouTube. A `Topic filter` button sits in the top bar — click it for all controls: enable toggle, check/uncheck topics, badges toggle, confidence threshold, add/delete/reset topics, model Load/Redownload + status, rescan.
5. First run: panel → **Model → Load model** (~260 MB first download, cached afterwards). If a download fails partway, **Redownload** (click twice) clears cached model files and fetches fresh.

## Configure

- **Model**: fixed to `Horizon-Labs/multilingual-zeroshot-small`, q8, WASM. No endpoint, no server.
- **Topics**: fully editable in the panel (Add / delete / Reset to defaults). The topic **name** is what the model matches (`This video is about {name}`) — keep names crisp and unambiguous. Descriptions are shown in the panel only.
- **Min confidence**: below this, videos are labeled `Other` instead of the top choice. Entailment scores are uncalibrated — retune on a few of your own videos.
- **Hiding**: unchecked topics get `display:none` via the `.ytf-hide` class.

## Files

```
manifest.json          MV3 (Brave/Chrome, CSP wasm-unsafe-eval for ONNX/WASM)
src/background.js      source: router (offscreen plumbing) + videoId result cache
src/background.bundle.js  generated by `bun run build` (git-ignored; what the manifest loads)
src/offscreen.html/js  offscreen document: owns the zero-shot model (WASM can't init in a worker)
src/offscreen.bundle.js   generated by `bun run build` (git-ignored)
src/vendor/ort/       vendored onnxruntime WASM runtime (git-ignored; extension CSP blocks remote imports)
src/content.js         YouTube DOM scan + top-bar button + panel (all controls)
src/content.css        badge + hide + panel styles
package.json           Bun project (pinned deps + `bun run build`)
icons/                 extension icons
```

## Notes / limits

- Model weights download from `https://huggingface.co` (cached via Cache API); ONNX WASM comes from `https://cdn.jsdelivr.net` (see `host_permissions`).
- YouTube changes DOM often — selectors cover old + new (`ytd-lockup-view-model`) layouts and re-scan on `yt-navigate-finish` + `MutationObserver`.
- Classification is title+channel only (no thumbnails/transcripts). Fully on-device; speed depends on your CPU.
- Labels/titles can be non-English; keep the hypothesis template and topic descriptions descriptive.
